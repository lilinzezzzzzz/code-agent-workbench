# Codex 聊天标题的工作区标签

1. 根据工作区路径取标签。路径中有名为 `worktrees` 的目录时，使用紧接其后的目录名。没有 `worktrees` 目录的有效主工作区路径使用 `primary`。路径缺失，或 `worktrees` 后缺少目录名时，标签未确定。
2. 默认格式为 `[<工作区标签>] <标题正文>`。用户明确提供新标题时，以指定标题作为正文。否则，根据目标聊天的工作上下文和实际工作内容，用简短措辞概括当前主要任务，尽量写明工作对象和目标。
   - 优先使用已知的目标聊天上下文。信息不足时，用 `read_thread`（`includeTurns: true`）按需读取目标聊天的相关轮次，结合用户明确的目标和最新的范围调整拟定正文。
   - 原标题准确概括当前任务时，可以沿用其正文。沿用时仅移除已根据原工作区路径确认的旧工作区前缀，保留其他方括号内容。新标签在标题开头只保留一次。
3. 需要更新时，比较拟定标题与当前标题。一致时直接使用现有标题。否则用 `set_thread_title` 显式传入目标聊天的 `threadId` 和 `source: codex`，核对目标 ID 和最终标题，必要时用 `read_thread` 重新读取元数据确认。

例如，聊天正在修复 DocFlow 的批量导入失败问题，并从主工作区附加到 `~/.codex/worktrees/ws-2154/docflow`，可将 `[primary] 按修复计划新建 worktree` 更新为 `[ws-2154] 修复 DocFlow 批量导入失败`。
