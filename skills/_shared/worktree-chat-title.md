# Codex 聊天标题的工作区标签

1. 根据工作区路径取标签。路径中有名为 `worktrees` 的目录时，使用紧接其后的目录名。没有 `worktrees` 目录的有效主工作区路径使用 `primary`。路径缺失，或 `worktrees` 后缺少目录名时，标签未确定。
2. 默认格式为 `[<工作区标签>] <标题正文>`。正文采用当前标题，用户提供新标题时采用用户的标题。沿用当前标题时，仅移除已根据附加前工作区路径确认的旧工作区前缀。保留其他方括号内容。新标签在标题开头只保留一次。
3. 需要更新时，比较拟定标题与当前标题。一致时直接使用现有标题。否则用 `set_thread_title` 显式传入目标聊天的 `threadId` 和 `source: codex`，核对目标 ID 和最终标题，必要时用 `read_thread` 重新读取元数据确认。

例如，聊天从主工作区附加到 `~/.codex/worktrees/ws-2154/docflow` 后，`[primary] 按修复计划新建 worktree` 更新为 `[ws-2154] 按修复计划新建 worktree`。
